# 구름헤럴드 지면보기 (신문 지면 웹사이트)

종이 신문을 그대로 옮긴 화면입니다.
**날짜를 골라** 그 날 신문을 펴고, **옆으로 넘기면** 종이가 넘어갑니다.

지금은 **2026년 9월 5일자 종이 3장(앞뒤 6면)** 을 만들어 둔 시험판입니다.
내용은 [gureumherald.com](https://gureumherald.com/) 에 실린 실제 기사 22건을 넣었습니다.

| 면 | 분야 | 면 | 분야 |
|---|---|---|---|
| A1 | 종합 | A4 | 국제 |
| A2 | 정치 | A5 | 오피니언 |
| A3 | 사회 | A6 | 스포츠·e스포츠 |

**종이는 양면입니다.** A1의 뒷면이 A2, A3의 뒷면이 A4입니다.
그래서 넘기면 진짜 신문처럼 뒷면이 왼쪽으로 넘어가고 다음 장의 앞면이 오른쪽에 나옵니다.

이 폴더 하나가 사이트 전부입니다. 통째로 옮겨도 그대로 돕니다.

```
(폴더 맨 위)
├── index.html        ← 독자가 보는 지면보기
├── admin.html        ← 기자가 쓰는 편집실
├── paper.css         ← 지면 모양 (신문 조판)
├── paper.js          ← 지면을 그리는 공통 코드
├── seed.js           ← 처음 자료 (자동 생성. 직접 고치지 마세요)
├── data/
│   └── paper.json    ← ★ 실제로 발행되는 내용
└── _seed/
    ├── articles.json ← 구름헤럴드에서 받아온 기사 원문
    └── build_seed.py ← articles.json → seed.js 를 만드는 스크립트
```

## 1. 열어 보는 법

`index.html` 을 그냥 더블클릭해도 열리기는 합니다. 다만 그때는 브라우저가
`data/paper.json` 읽기를 막아서 **`seed.js` 의 처음 자료**가 보입니다.
편집한 내용까지 제대로 보려면 작은 서버를 하나 띄우세요.

```bash
cd <이 폴더>
python3 -m http.server 8000
# → http://localhost:8000/         지면보기
# → http://localhost:8000/admin.html  편집실
```

## 2. 독자 화면 (`index.html`)

| 하는 일 | 방법 |
|---|---|
| 다음 장으로 | 종이 **오른쪽 끝을 잡아 왼쪽으로 끌기** · `다음 ▶` · `→` 키 |
| 앞 장으로 | 종이 **왼쪽 끝을 잡아 오른쪽으로 끌기** · `◀ 앞` · `←` 키 |
| 특정 면으로 | `A1` ~ `A6` 단추 |
| 두 면 나란히 / 한 면씩 | `펼쳐 보기` · `한 면씩` 단추 (좁은 화면은 처음부터 한 면씩) |
| 다른 날짜 | 아래 가운데 **날짜 고르개** (◀ 과거 / ▶ 최신) |
| 기사 크게 읽기 | **기사를 누르면** 큰 글씨로 열립니다 (`Esc` 로 닫기) |

### 지면에 실리는 글은 '요약'입니다 — 잘리는 글자가 없습니다

지면은 크기가 정해져 있는데 기사 원문은 길이가 제각각입니다.
그대로 얹으면 칸을 넘겨 **글이 중간에서 잘립니다.** 보기 흉하고 읽을 수도 없습니다.

그래서 지면에는 **칸에 맞춰 줄인 글**을 싣고, 기사를 누르면
`구름헤럴드에서 기사 전문 보기 ↗` 로 원문(`gureumherald.com/article/…`)에 갑니다.
종이 신문이 같은 기사를 지면판과 온라인판에서 다르게 싣는 것과 같은 방식입니다.

여섯 면 모두 **필요한 높이 = 지면 높이(1340px)** 로 정확히 맞춰 두었습니다.

### 칸 높이를 px 로 적지 않습니다

칸은 글 분량만큼 자라고, **남는 자리는 광고 칸이 받습니다**(`fill`).
그래서 요약을 고쳐도 지면이 어긋나지 않습니다.
넘치면 편집실 위쪽 안내 상자가 **몇 px 넘쳤는지** 바로 알려 줍니다.

### 남이 쓴 글의 줄 나눔은 손대지 않습니다

칼럼 「존재하지 않는 님을 사랑한다는 것」처럼 **행을 나눠 쓴 글**은
`verse` 로 표시해 들여쓰기 없이 줄을 그대로 살립니다.
글자뿐 아니라 줄을 나누는 것도 남의 글에서는 손대면 안 되는 부분입니다.

### 본문이 단(段)을 넘어가는 것은 정상입니다

신문 본문은 좁은 단을 위에서 아래로 흐르다가 단이 끝나면 다음 단 맨 위로 이어집니다.
문장이 단 경계에서 끊겨 보이는 것은 신문 조판 그대로이며, 잘린 것이 아닙니다.
문단은 빈 줄이 아니라 **첫 줄 들여쓰기**로 구분합니다 — 이것도 신문 방식입니다.

### ⚠️ 한 기사의 단 사이에는 세로줄을 긋지 않습니다

신문에서 **세로 괘선은 서로 다른 기사를 가르는 선**입니다.
한 기사의 본문은 첫 단 아래에서 다음 단 위로 이어지는 하나의 글이므로,
그 사이에 선을 그으면 한 기사가 여러 토막으로 갈라져 보입니다.

기사끼리의 경계는 칸(`.blk`)의 왼쪽 테두리가 이미 맡고 있습니다.
`paper.js` 의 본문 스타일에 `column-rule` 을 다시 넣지 마세요.

### 지면 제목과 원래 제목은 다릅니다

구름헤럴드 기사 제목은 온라인용이라 깁니다.
그대로 큰 글씨로 얹으면 제목만 네 줄이 되어 기사가 안 들어갑니다.

그래서 칸마다 **지면 제목**(신문에 실리는 짧은 제목)과
**원래 제목**(전문 보기에 뜨는 본래 제목)을 따로 둡니다.
지금 들어 있는 지면 제목은 제가 줄여 놓은 것이니 **편집실에서 마음대로 고치세요.**

| 지면 제목 | 원래 제목 |
|---|---|
| 파주시 3차 추경 2조 6,085억 원 | 경기 파주시, 2026년도 제3회 추가경정예산안 2조 6,085억 원 규모 편성… |
| ‘GTX-A’ 타고 커지는 파주 운정 | ‘GTX-A 수혜’ 입고 경기 북부 중심 중 하나에 ‘파주 운정’… |
| 장동혁의 배수진 ‘중진 용퇴론’ | ‘1.5선’ 장동혁의 배수진… ‘중진 용퇴론’ 카드로 당권파 정면 돌파할까 |
| 오세훈 1심 벌금 1000만원… 시장직 상실 위기 | ‘여론조사비 대납 의혹’ 오세훈 1심서 벌금 1000만원… 시장직 상실 위기 |
| 유시민의 신(新)재건축론, 여권 분열 부르나 | ‘분열의 정치’ 유시민의 신(新)재건축론… 안정적 국정 운영 발목 잡나 |

나머지 세 건(칼럼)은 제목이 짧아 그대로 썼습니다.

## 3. 편집실 (`admin.html`)

왼쪽부터 **발행일 → 지면 → 칸** 순서로 좁혀 들어가고,
가운데에서 내용을 고치면 **오른쪽 미리보기에 곧바로** 반영됩니다.

### 칸의 종류

| 종류 | 쓰임 |
|---|---|
| **기사** | 눈썹(분야) · 지면 제목 · 부제 · 사진 · 본문 · 기자 이름 · **필자 사진**(칼럼) |
| **표** | 통계표. 첫 칸은 왼쪽, 숫자 칸은 오른쪽으로 자동 정렬됩니다 |
| **그래프** | 가로 막대. **기준선**을 그으면 넘는 값과 못 미치는 값이 색으로 갈립니다 |
| **인용** | 기사에서 뽑아 크게 싣는 발언 |
| **광고 자리** | **비워 두는 칸.** 사진을 넣거나 **글자 광고**를 짜 넣을 수 있습니다 |
| **알림 상자** | 사고(社告) · 정정 · 안내문 |
| **제호** | 1면 맨 위 `구름헤럴드` 머리. 좌·우에 광고 자리가 붙어 있습니다 |
| **면 머리** | 2면부터 맨 위에 붙는 `A2 · 정치·오피니언 · 날짜` 줄 |

### 표와 그래프는 줄글로 씁니다

편집실에서 한 줄이 표의 한 줄입니다. 칸은 **쉼표**로 나눕니다.

```
명동 네이처리퍼블릭 부지, 1억 8,840만원
도봉동 산30 자연림, 6,940원
```

그래프도 같습니다 — `항목 이름, 숫자` 한 줄씩. **기준선**을 정하면 그 값에 점선이
그어지고, 못 미치는 막대는 붉게 표시됩니다. 최대값은 기준선보다 조금 크게 잡아야
점선이 막대 안쪽에 보입니다(예: 기준 100이면 최대 115).

### 사진을 본문 중간에 놓고 글이 옆으로 흐르게

기사 편집에서 `사진 옆으로 흐를 문단 수`(`imgSide`)를 정하면, 그만큼의 문단이
사진 **왼쪽 좁은 단**으로 내려오고 나머지 본문은 **사진 아래에서 지면 폭 전체로**
이어집니다. 원본 신문의 머릿기사와 같은 모양입니다.

> ⚠️ CSS 다단(`column-count`) 안에서는 `float` 이 한 단 안에 갇힙니다.
> 그래서 사진을 띄우는 대신 **격자로 나란히** 놓았습니다.

**사진 높이를 옆 글 높이에 맞추세요.** 사진이 더 길면 글 옆에 흰 여백이 남습니다.
지금은 1면·2면 모두 1~6px 안쪽으로 맞춰 두었습니다.

### 서체는 네 갈래로 씁니다

하나로 통일하면 어느 기사가 중요한지 눈에 들어오지 않습니다.

| 쓰임 | 서체 | 굵기 | 갈래 |
|---|---|---|---|
| 제호 | `Hahmlet` | 900 | 명조 |
| **머릿기사 제목** | `Black Han Sans` | — | **고딕** |
| 나머지 기사 제목 | `Noto Serif KR` | 700 · 900 | 명조 |
| 본문 | `Nanum Myeongjo` | 400 | 명조 |

**머릿기사(`size="lead"`) 한 꼭지만 고딕입니다.** 조선일보 1면을 실측해 보니
머릿기사 하나만 고딕이고 나머지 제목은 전부 명조였습니다. 서체를 바꾸는 것
자체가 "이게 오늘의 톱"이라는 신호입니다. 크기만 키우는 것보다 훨씬 강하게 읽힙니다.

`Black Han Sans` 는 굵기가 한 종류뿐이라 `font-weight` 를 올려도 소용없습니다.
글자 자체가 이미 아주 굵고 각져 있습니다.

**빠진 글자가 하나 있습니다.** 이 서체에는 가운뎃점(`·`)·줄임표(`…`)·한자가
없습니다. 머릿기사 제목에 이런 글자가 들어가면 그 글자만 뒤에 받쳐 둔
`Gothic A1` 900 으로 나옵니다. 같은 고딕 계열이라 크게 튀지는 않지만,
머릿기사 제목에는 되도록 안 쓰시는 편이 깔끔합니다.

### PDF 로 내려받기

지면보기 아래쪽 **「PDF 내려받기」** 단추를 누르면 인쇄 창이 뜹니다.
거기서 *대상*을 **「PDF로 저장」** 으로 고르시면 여섯 면이 A4 한 장에 한 면씩
들어간 PDF 가 저장됩니다.

지면을 그림으로 굽지 않고 브라우저의 인쇄 기능을 그대로 씁니다. 그래야
**글자가 글자로 남아서** — 그림이 아니라 — 아무리 확대해도 또렷하고,
파일도 1MB 안팎으로 가볍습니다. 글자를 복사하거나 PDF 안에서 검색할 수도 있습니다.

넘기는 종이는 3차원으로 뒤집혀 있어 그대로는 인쇄되지 않습니다. 그래서
단추를 누르면 여섯 면을 평평하게 다시 그린 뒤 인쇄 창을 엽니다
(`index.html` 의 `buildPrintout`, `paper.css` 의 `@media print`).

지면 한 장이 1000px 이고 A4 가로가 210mm(= 793.7px)이라 `0.7937` 배로
줄이면 딱 맞습니다.

### 면 번호는 모든 면 아래에 붙습니다

`구름헤럴드 · 발행일 · 면 이름`이 지면 맨 아래에 자동으로 들어갑니다.
칸을 따로 만들지 않아도 되고, 지울 수도 없습니다 — 신문은 어느 면에나 번호를 답니다.

### 칼럼에는 필자 사진이 붙습니다

기사 편집에서 `필자 사진`을 켜면 제목 옆에 자리가 생깁니다. 사진 주소를 넣지 않으면
점선 상자로 남고, 나중에 주소만 적으면 채워집니다.

### 지면은 12단 격자입니다

칸마다 **너비(1~12단)** 를 정합니다. 너비 합이 12를 넘으면 자동으로 다음 줄로 내려가고,
줄 높이는 글 분량만큼 알아서 정해집니다.

- 통단 기사·광고 → 12단
- 좌우 2단 구성 → 8단 + 4단
- 3등분 → 4단 + 4단 + 4단

### ⚠️ 넘침 안내를 꼭 보세요

편집실 위쪽 안내 상자가 브라우저가 그린 결과를 **실제로 재서** 알려 줍니다.

- **초록색** — 지면에 딱 맞습니다
- **주황색** — `○○px 넘칩니다`. 요약을 줄이거나 사진 높이를 낮추세요

px 를 더하는 계산이 아니라 그려진 것을 재는 방식이라 틀릴 일이 없습니다.

## 4. 광고는 왜 비워 두었나

사장님이 채우실 자리이기 때문입니다.
지금은 점선 상자에 **문구와 대략 크기**만 적혀 있습니다.

| 광고 자리 | 크기 |
|---|---|
| 제호 왼쪽 · 오른쪽 | 각 약 300 × 74 |
| 1면 하단 통광고 | 약 940 × 250 |
| 2면 하단 통광고 | 약 940 × 310 |

### 채우는 방법 두 가지

**① 글자 광고 (권장)** — 편집실에서 `이 칸을 어떻게 채울까요`를 **글자 광고를 짠다**로
바꾸면 어깨 딱지·큰 문구·작은 딱지·전화번호·바탕색을 넣어 신문 하단 통광고 모양이 나옵니다.
**한글이 또렷하게 나오고 어느 크기에서도 깨지지 않습니다.**

**② 배경 사진 + 글자** — ①번에 **배경 사진 주소**를 더하면 사진 위에 한글이 얹힙니다.
사진 위에 옅은 막이 한 겹 깔려 글자가 묻히지 않습니다(`scrim` 으로 조절).

`images/ads/cloud-banner.webp` 를 하나 넣어 두었습니다 —
Higgsfield 로 만든 새벽 하늘 그림입니다(1400×594, 14KB).

**③ 사진만** — 완성된 광고 이미지 주소(URL)를 넣으면 그 자리를 통째로 채웁니다.

> ⚠️ **AI 이미지 생성기로 광고를 통째로 만들지 마세요.**
> 그림은 잘 나오지만 **한글 문구가 뭉개져 나옵니다.** 배경만 AI 로 만들고
> 글자는 ①②번처럼 지면이 직접 그리게 하는 것이 맞습니다.

파일을 직접 올리는 기능은 이미지 저장소가 필요해서 아직 넣지 않았습니다.
지금은 `images/ads/` 에 파일을 넣고 그 경로를 적으면 됩니다.

## 5. 고친 내용을 진짜로 내보내는 법

편집실에서 고친 내용은 **그 브라우저 안에만** 저장됩니다.
다른 사람 화면에는 아직 안 보입니다. 두 걸음이 남습니다.

1. 편집실 위쪽 **`내보내기 (paper.json)`** → `paper.json` 파일이 내려옵니다
2. 그 파일로 **`data/paper.json` 을 덮어쓰고** 저장소에 올립니다

이렇게 나눈 이유는 **아직 안 끝난 원고가 손님에게 보이지 않게** 하기 위해서입니다.
쓰다 만 기사가 저절로 발행되면 곤란합니다.

- **`지면으로 보기`** 를 누르면 `index.html?draft=1` 이 새 창으로 열립니다.
  올리기 전에 실제 지면 모양으로 확인하는 용도입니다.
- **`처음 자료로`** 를 누르면 편집 중이던 내용을 버리고 `seed.js` 상태로 돌아갑니다.

### ⚠️ 지금 편집실에는 비밀번호가 없습니다

전부 브라우저 안에서만 도는 화면이라, 자물쇠를 걸어도 **흉내에 그칩니다.**
누구든 `admin.html` 을 열 수는 있지만, **그 사람이 고친 내용은 그 사람 브라우저에만 남고**
`data/paper.json` 을 바꾸려면 저장소에 올리는 권한이 있어야 합니다.
그래서 지금 구조에서는 실제 지면이 남의 손에 바뀌지 않습니다.

나중에 **브라우저에서 바로 발행**하고 싶어지면 그때는 백엔드가 필요합니다.
필요한 것은 세 가지뿐입니다 — 지면을 담아 둘 곳(데이터베이스),
비밀번호를 확인해 주는 곳(로그인), 그리고 그 둘을 잇는 주소 몇 개.
**구름헤럴드 전용으로 새로 만듭니다.** 다른 사이트의 것을 끌어다 쓰지 않습니다.

## 6. 기사 자료를 다시 받아 오려면

`_seed/articles.json` 은 구름헤럴드의 공개 API 에서 받아온 기사 원문입니다.

```
https://gureumherald.com/api/trpc/articles.getPublished
```

새로 받아 넣은 뒤 아래를 실행하면 `seed.js` 가 다시 만들어집니다.

```bash
python3 _seed/build_seed.py
```

어느 기사를 몇 단으로 어디에 앉힐지는 `build_seed.py` 안의
`A1` · `A2` 목록에 적혀 있습니다.

> **사진**은 구름헤럴드가 쓰는 저장소(`res.cloudinary.com`)를 그대로 가리킵니다.
> 이 폴더에 사진 파일을 복사해 두지 않았으므로, 원본 주소가 바뀌면 사진이 사라집니다.

## 7. 이 폴더는 혼자 돕니다

**구름헤럴드는 다른 어떤 사이트와도 섞이지 않습니다.** 지금도, 앞으로도 그렇습니다.

- 이 폴더 밖의 파일을 **하나도** 읽지 않습니다 (css·js·이미지 전부 이 안에 있습니다)
- 이 폴더 밖의 어떤 파일도 이 폴더를 가리키지 않습니다
- 배포도 따로입니다 — 이 폴더만 통째로 올리면 그대로 돕니다 (정적 파일이라 서버가 필요 없습니다)

그래서 **이 폴더를 그대로 잘라내 다른 저장소로 옮겨도** 아무것도 고칠 필요가 없습니다.

바깥에서 들어오는 것은 딱 두 가지, 둘 다 인터넷 주소입니다.

| 무엇 | 어디서 | 없으면 |
|---|---|---|
| 제목 글씨체 (나눔명조·본명조) | `fonts.googleapis.com` | 시스템 명조로 대체됩니다 |
| 기사 사진 | `res.cloudinary.com` (구름헤럴드 사진 저장소) | 회색 칸으로 남습니다 |

둘 다 없어도 지면은 정상으로 열립니다.
